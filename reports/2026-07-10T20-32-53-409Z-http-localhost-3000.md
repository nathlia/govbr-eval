### F-103 — [serious] emag-4.4

- **Regra:** Possibilitar que o elemento com foco seja visualmente evidente. O gov.br DS usa contorno tracejado dourado (#c2850c, offset 4px). Não usar outline: none sem substituto visível. (WCAG 2.4.7) — fonte: emag
- **Elemento:** `#TC-B-10 > button` em http://localhost:3000/
- **Observado:** No estado :focus, outline-style: none e box-shadow: none — nenhum indicador visual de foco
- **Esperado:** Indicador de foco do DS: outline dashed 4px #c2850c com offset 4px (observado nos botões conformes da mesma página)
- **Classificação:** semantic / interaction · via explicit

```html

```

<details><summary>Trilha de raciocínio</summary>

Supressão de foco via CSS não é detectada pelo axe-core (que analisa a árvore de acessibilidade, não estilos computados de foco). Regra emag-4.4 obtida via get_emag_rules(section=4).

</details>
